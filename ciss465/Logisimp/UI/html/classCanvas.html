Detailed Description

This class provides an interactive graphical workspace for circuit components.

Canvas is responsible for displaying and managing the GUI for the workspace of the logic simulator

The program uses QOpenGLWidget OpenGl rendering and QPainter for drawing the grid and circuit elements

Current Features include:

  • Rendering a grid-based workspace
  • Displaying AND, OR, and NOT gates
  • Dragging a gate using the leftmouse button
  • Panning the grid using either the middle mouse button or using the WASD keys
  • Zooming in and out toward the mouse cursor
Note
Circuit simulation logic is not yet integrated into the graphical user interface

void Canvas::mouseMoveEvent ( QMouseEvent * event)
overrideprotected

Processes mouse movement within the workspace.

The behavor depends on the current interaction state

When drawing wire state is true

  • requests a redraw to the screen

When dragging state is true:

  • Converts mouse coordinates to world coordinates
  • Applies the drag offset
  • Snaps the gate position ot the nearest grid point
  • Requests a redraw of the screen

When panning state is true:

  • Calculate mouse displacement
  • Adjust camera position relative to zoom
  • Requests a redraw to the screen

    • Set dragging offset coordinates

◆ wheelEvent()

void Canvas::wheelEvent ( QWheelEvent * event)
overrideprotected

Changes the workspace zoom using the mouse wheel.

Zooming is centered at the current mouse position

The function first records the world coordinates beneath the cursor. It then modifies the zoom factor and recalculates the camera position so the same world point remains beneath the cursor.

The zoom factor is limited to [0.5, 10.0].

Parameters
eventQT mouse wheel event containing the scroll direction and cursor position
Note
Each wheel event scales zoom by a factor of 1.1.

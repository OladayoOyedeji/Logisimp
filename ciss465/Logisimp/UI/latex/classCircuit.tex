\doxysubsection{Detailed Description}
Abstract base class for graphical circuit elements. 

Defines the shared positions and rendering interface for objects displayed in the circuit workspace

Derived classes must implement \doxylink{classCircuit_a20f38173696bbfb00a85fd625a02bd45}{draw()} to provide their own visual representation

\begin{DoxyNote}{Note}
Positions are stored within world coordinates
\end{DoxyNote}

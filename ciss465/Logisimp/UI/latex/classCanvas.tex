\doxysubsection{Detailed Description}
This class provides an interactive graphical workspace for circuit components. 

\doxylink{classCanvas}{Canvas} is responsible for displaying and managing the GUI for the workspace of the logic simulator

The program uses QOpen\+GLWidget Open\+Gl rendering and QPainter for drawing the grid and circuit elements

Current Features include\+:
\begin{DoxyItemize}
\item Rendering a grid-\/based workspace
\item Displaying AND, OR, and NOT gates
\item Dragging a gate using the leftmouse button
\item Panning the grid using either the middle mouse button or using the WASD keys
\item Zooming in and out toward the mouse cursor
\end{DoxyItemize}

\begin{DoxyNote}{Note}
\doxylink{classCircuit}{Circuit} simulation logic is not yet integrated into the graphical user interface
\end{DoxyNote}

Changes the workspace zoom using the mouse wheel. 

Zooming is centered at the current mouse position

The function first records the world coordinates beneath the cursor. It then modifies the zoom factor and recalculates the camera position so the same world point remains beneath the cursor.

The zoom factor is limited to \mbox{[}0.\+5, 10.\+0\mbox{]}.
